# kvartirnik-site

Сайт «Квартирник у Маши Боруха» — вторая версия, экспортированная из Notion с подстраницами.

🌐 **Сайт:** https://mariaborukha.github.io/kvartirnik-site/

## Файлы

| Файл / папка | Описание |
|---|---|
| `index.html` | Главная страница сайта |
| `Квартирник у Маши Боруха/` | Папка с ресурсами, экспортированными из Notion |

| `Вакансии квартирника...html` | Страница вакансий |

| `Кто делает квартирник...html` | Страница о команде |
